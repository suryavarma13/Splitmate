# Planned API modules

Auth: register, login, logout, verify email, forgot/reset password.
Friends: search users, send/accept/reject/cancel requests, list/remove friends.
Groups: create/list/update groups, manage members, email invitations.
Expenses: create/list/detail/update/delete, equal/percentage/custom split.
Balances: balances overview, member balances, settlement suggestions.
Settlements: record/list/detail.
Payments: initiate, status, provider webhook.
Notifications: list, mark read.
Receipts: upload, retrieve, delete.
Reports: summary, category breakdown, settlement report, export.

These routes are placeholders until the APIs are implemented and tested.
